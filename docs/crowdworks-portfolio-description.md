# CrowdWorks ポートフォリオ掲載用資料

## 作品タイトル

架空和菓子店「菓寮 月白」ブランドサイト(Concept Project)

## 短い説明(100文字程度)

架空の和菓子店のブランドサイトを、企画・コピー・デザインから実装・検証まで一貫して制作。伝統色と縦書きを活かした和のデザインで、レスポンシブとアクセシビリティに配慮したReact + TypeScript製の1ページサイトです。

## 詳細な作品説明

「月白(つきしろ)= 月が昇る直前に空が白む色」という伝統色の名を持つ、架空の和菓子店を題材にしたコンセプトサイトです。

夜空のファーストビューから、スクロールとともに空が白み、月白色の世界へ移っていく——という語源そのものを体験に変換した構成が特徴です。菓子と店舗の写真は画像生成AIで作成し(プロンプトは docs/image-prompts.md)、青海波の文様と周辺地図はSVGで自作して、ブランドの世界観を統一しています。

実案件を想定し、以下を織り込んでいます。

- 予約(コンバージョン)へ自然に誘導する情報設計(価値提示 → 商品 → 中間CTA → 価格 → 信頼形成 → 店舗情報 → 予約)
- 業務ルールを反映したフォームバリデーション(受取日は3日後〜60日先、定休日の水曜は選択不可、ひらがな・電話・メール形式の検証)
- スマートフォンでの読みやすさを優先したレスポンシブ設計(360px〜)
- アクセシビリティ(キーボード操作、フォーカス管理、スクリーンリーダー対応、reduced-motion対応)

※ 架空ブランドのConcept Projectであり、実在の店舗・実績とは関係ありません。

## 想定クライアント

和菓子店・菓子舗・カフェ・料飲店など、世界観を大切にしたい店舗ビジネスの単体サイト/ブランドサイト/予約導線付きLP

## 担当範囲

企画 / 情報設計 / コピーライティング / デザイン(トークン設計・SVGイラスト制作含む) / 実装 / テスト

## 使用技術

React 19 / TypeScript(strict) / Vite 8 / CSS Modules / Vitest + Testing Library / oxlint

## 工夫した点

- ブランド名の語源「夜空が白む瞬間」をスクロール体験として設計し、テンプレート的な構成(同サイズカードの羅列など)を避けた
- 見出し・菓銘に縦書き(writing-mode: vertical-rl)を使い、日本語サイトならではの組版を実装
- 配色は日本の伝統色から論理的に導出し、CSSカスタムプロパティのデザイントークンとして一元管理
- フォームは純粋関数のバリデーション+UIの2層に分け、境界条件(日付・定休日など)を自動テストで担保
- 日本語Webフォントをunicode-rangeスライスでセルフホストし、外部CDN非依存で表示を安定化

## レスポンシブ対応

360 / 375 / 768 / 1024 / 1440px で検証済み。モバイルは縮小版ではなく、ナビゲーション(ドロワー)、コレクションの並び、縦書き要素の配置を再設計しています。

## 対応可能な案件

- 店舗・ブランドの単体Webサイト/LP制作(デザインから実装まで一貫対応)
- 既存サイトのレスポンシブ対応・アクセシビリティ改善
- React / TypeScriptによるフロントエンド実装
