# 設計根拠 — 市場調査の原則と「菓寮 月白」の対応

本プロジェクトは、Instagram Reelsで紹介されている商業Webサイト12件の市場調査(業界横断・重複排除)から抽出した設計原則をもとに設計しています。調査の生データには第三者の投稿情報が含まれるため公開リポジトリには含めず、本書では抽象化した原則と、それを本サイトがどう実装しているかだけを記録します。

## 調査から得た設計軸

調査したサイトは大きく2軸に分かれました。

| 軸 | 有効な業界 | 信頼の作り方 |
|---|---|---|
| 世界観・情緒型 | 高級不動産・高級車・飲食など高級商材 | 余白・質感・トーンを「体験」させる |
| 明快さ・信頼型 | 製造B2B・フィンテック・SaaS | 情報階層と検証可能な具体で語る |

上生菓子は少量生産の高級嗜好品であり、**世界観・情緒型**を採用しました。情報量で説得するのではなく、「月白」という色名の語源をスクロール体験(夜空→夜明け→月白の地色)に変換し、世界観そのものを信頼の担保にしています。

## 原則 → 実装の対応

### 1. ヒーローは「短いコピー+主役ビジュアル+明確な次アクション」の3点セット

高級商材の有効パターンは、情緒的な短文コピーと大判ビジュアルの組み合わせでした。

- 情緒コピー(縦書き): 「今宵の月を、菓子にうつす。」
- 業種の即時理解: サブコピーに「上生菓子」「菓子店」を明示(訪問者は数秒で「何のサイトか」を判断するため)
- 主役ビジュアル: 月と暈(サイト内で唯一の発光表現)
- 具体的な動詞句CTA: 「季節の菓子を予約する」

### 2. CTAは「理解が最高潮に達した直後」に置く

調査では、成果を出しているサイトほどCTAを「見て欲しくなった直後」「比較し終えた直後」に配置していました。

- 季節の菓子(商品の世界観を見た直後)→ 中間CTA帯「ご予約へ進む」
- お品書き(価格を比較した直後)→ 進物包装の案内とともに予約フォームへの導線
- 店舗案内(「売り切れ仕舞い」という希少性を理解した直後)→ 「ご予約」をリンク化
- ヘッダーにも常設の「ご予約」導線

### 3. 信頼は「体験できる質感」で作る(架空実績は使わない)

B2Bでは実測数値が信頼を作りますが、高級商材は質感が信頼を作ります。本サイトは架空ブランドのため数値実績は一切書かず、代わりに製法の具体描写(銅鍋・絹漉し・掌の温度・へら一本)と職人の経歴だけで専門性を伝えています。

### 4. AI生成サイトに見える特徴を避ける

調査で「AI量産物」に見える主因とされたのは、無意味なグラデーション・文脈のない3D・均質なダークテーマ・業界クリシェ・情報過多でした。

- 配色はすべて日本の伝統色(月白・鉄紺・小豆・白緑・銀鼠)から採取し、単一アクセント(小豆)で規律
- 夜空は「月白」の語源という文脈があるダークであり、スクロールで明るい地色へ遷移する(均質ダークの回避)
- ビジュアルは汎用3Dではなく、意味を持つ自作SVG(菓子・青海波・簡易地図)
- 1セクション1メッセージを維持

### 5. モーションは目的がある箇所のみ

没入型演出は「世界観を体感させる」目的がある時だけ価値を持つ、という調査結論に従い、スクロール演出は3種に限定しています: フェードイン(視線の順序付け)、青海波のゆらぎ(水面=世界観)、ヘッダーの透過遷移(夜→昼の追体験)。加えて hover・押下・ドロワー開閉のマイクロインタラクションを opacity / translate / scale のみ・モーショントークン基準で統一しています。すべて `prefers-reduced-motion` で停止します。

### 6. モバイルは情報を削る

モバイルはデスクトップの縮小ではなく、縦書き見出しの位置・コレクションの並び・ナビゲーション(ドロワー)を別レイアウトで設計し、ヒーローはコピー・CTA・月に絞っています。

## 採用しなかった知見とその理由

- **飲食業界の「暖色で食欲に訴える」**: カフェ等のカジュアル業態で有効な原則。本ブランドは「静けさ」を売る高級嗜好品のため、暖色はCTA・現季節バッジ・店舗マーカーの小豆色に限定し、全面的な暖色化はしていません。
- **信頼バッジをファーストビュー近くに置く**: 実在の評価サービスのバッジは架空ブランドでは虚偽表示になるため使用せず、Concept Projectの注記を代わりに明示しています。
- **没入型WebGL**: 世界観の提示はCSS/SVGで足りており、モバイル・低速環境の負荷に見合わないため不採用。
