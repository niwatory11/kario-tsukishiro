# 視覚品質レビュー

UIに変更を加えたら、必ずこの手順で実表示を確認する。

## 手順

1. `npx vite --port 5173` をバックグラウンドで起動する
2. Playwright(scratchpadに `npm i playwright` 済みであること)で 360 / 375 / 768 / 1024 / 1440px のスクリーンショットを撮る。全revealを発火させるため一度最下部までスクロールしてからフルページを撮影する
3. 各幅で `document.documentElement.scrollWidth <= document.documentElement.clientWidth` を評価し、横スクロールが出ていないか機械的に検査する
4. スクリーンショットを目視し、次の観点で確認する
   - ファーストビューだけで「和菓子店のサイト」と分かるか
   - 見出し・縦書き要素が画面外へ出ていないか
   - カード等サイズの羅列になっていないか(段差・ジグザグのリズムが保たれているか)
   - CTAが各画面幅で押しやすいか(44px以上)
   - SVGイラストが意図しない形(顔に見える等)になっていないか
5. `page.emulateMedia({ reducedMotion: 'reduce' })` で演出が止まることを確認する
6. 問題を見つけたら、レビュー文だけで終わらせず必ずコードを修正して再撮影する

## 注意

- Playwrightの要素スクリーンショットでは、fixed要素(ヘッダー・スキップリンク)が
  ページ中央に写り込むstitchingアーティファクトが出ることがある。
  異常に見えたら通常のビューポート撮影で再確認してから判断する
